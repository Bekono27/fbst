500+ бүртгэл удирдах зорилтот хүчин чадал

500+ бүртгэлийн ажиллагаа болон зэрэг ажиллах хүчин чадал хараахан туршигдаагүй. Энэ нь бэлэн Facebook бүртгэлийн нийлүүлэлт биш.

Одоо байгаа боломж

Локал бүртгэлийн сан, Page ID ба холбоос хадгалах, бүлгийн лавлах, нийтийн мэдээллийг GitHub руу нийтлэх, зардлын тооцоолуур.

Төлөвлөсөн автоматжуулалт

Зөвшөөрөгдсөн бүртгэл, хуудасны Like, Share, Comment ажлыг дараалал, хуваарь, үр дүнгийн хяналттай автоматжуулах зорилт. Эдгээр хөдөлгүүр одоогоор бэлэн биш.

Page үүсгэх ба хяналт

Локал хөдөлгүүр боловсруулагдсан. Бодит Meta ажиллагаа, үүсгэсэн Page ID болон алдааны сэргэлтийг бүрэн баталгаажуулах шаардлагатай.

Прокси ба ажиллуулах зардал

Нийтийн прокси лавлах болон төлбөртэй үйлчилгээний холбоос нээлттэй. Прокси холболт хараахан нэмэгдээгүй. IP / дата, сервер, интернетийн зардал тусдаа; нэг үйлдлийн үнэ хэмжилтийн дараа тогтоно.
